# Конструктор сценариев — прототип редактора (React Flow)

Визуальный редактор сценариев (Flow) ботов **meta-bot-core**. Прототип-каркас на
**React + [React Flow](https://reactflow.dev) (`@xyflow/react`)**.

> Это один из трёх продуктов проекта: (1) бэкенд-ядро (Python/FastAPI), (2) mini app
> (TypeScript), (3) **этот редактор** (фронтенд). Редактор **не исполняет** бота —
> он собирает сценарий как **данные** (агрегат `Flow`) и отдаёт на backend; в рантайме
> их интерпретирует Flow Engine. Модель типов — `memory-bank/domain/flow-blocks.md`.

## Запуск

```bash
cd frontend/constructor
npm install
npm run dev      # → http://localhost:5173
```

Сборка/проверка компиляции: `npm run build`.

## Что уже есть

- **Палитра** — 4 триггера входа + 8 блоков (`send_message`, `show_buttons`, `ask`,
  `condition`, `open_mini_app`, `save`, `http_request`, `custom_code`🔒). Блоки,
  недоступные на выбранной платформе, приглушены (заглушка CapabilityMatrix, BR-006).
- **Холст** — узлы = блоки, стрелки = переходы. `condition` даёт две ветки да/нет
  (зелёный/серый порты). Drag-and-drop из палитры, соединение узлов мышью.
- **Панель настройки** — поля параметров для каждого типа блока; у `custom_code` —
  редактор кода + бейдж песочницы (BR-004).
- **Верхняя панель** — имя бота, бейдж платформы (Telegram/MAX, «замок» = неизменяема,
  BR-002), переключатель платформы, «Проверить» (валидация BR-001), «Опубликовать»
  (гейт: недоступна, пока сценарий не проходит проверку), тумблер `{ } JSON`.
- **JSON-панель** — живой агрегат `Flow`, наглядно показывает: сценарий это данные.

## Чего ещё нет (следующие шаги)

- Реальный Admin API (пока Flow живёт в состоянии React, без backend).
- Полноценная CapabilityMatrix с backend + platform-specific блоки.
- Превью-эмулятор телефона (Telegram/MAX) и предпросмотр mini app.
- Автосохранение, undo/redo, режим «доска состояний» (из build-spec дизайн-роя).
